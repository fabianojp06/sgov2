## Purpose & context

- Fabiano is a requirements analyst working solo on a ServiceNow implementation project at his company
- Primary goal: build a centralized data foundation in ServiceNow that can generate delivery reports across 8+ organizational areas
- Project is in early planning stages; no ServiceNow environment provisioned yet
- The affected areas are not yet aware the initiative exists — Fabiano is responsible for introducing and driving it from scratch

## Current state

- At the end of Phase 1 planning, with a full four-phase implementation roadmap in place
- Complete Phase 1 kit delivered, comprising: a Kickoff Presentation to introduce the project to stakeholders; a structured Interview Script (five thematic blocks with annotation spaces and field-mapping tables); a Requirements Map for post-interview consolidation with pre-populated common fields and a multi-area status tracker; and a Communications Pack with email templates for project introduction, meeting invitations, and post-interview follow-ups
- All Phase 1 materials were delivered as .docx files
- Immediate next step is likely stakeholder outreach and conducting discovery interviews across the 8+ areas

## On the horizon

- Phase 2: Data Modeling (~3 weeks) — designing the data structure based on Phase 1 findings
- Phase 3: Configuration and Data Entry (~2 weeks)
- Phase 4: Reports and Dashboards (~2 weeks)
- Followed by go-live and a continuous improvement cycle

## Approach & patterns

- Favors structured, comprehensive deliverables with supporting materials, not just high-level guidance
- Prefers output in Word (.docx) format for documentation
- Works well with phased roadmaps and modular kits organized by project phase
- Operates in a solo capacity, so toolkits need to be self-contained and ready to use without team support

## Tools & resources

- ServiceNow — target implementation platform (environment not yet provisioned)
- Word/.docx — primary format for project documentation and stakeholder materials
